# Jamh Airlines website

A fictional Jamh Airlines website with a client-side demo flight-search and itinerary-selection flow.

## Open it

Open `index.html` for the landing page, or `jamhairlines.html` for the full website. Keep `styles.css` and `script.js` in the same folder as the HTML files.

## Demo booking flow

1. Enter an origin and destination using the airport suggestions. Dublin (DUB) is included; Ethanburgh Highridge is intentionally excluded because Jamh Airlines does not serve it.
2. Choose trip type, dates, cabin and passenger count, then select **Search flights**.
3. Select one of the sample itineraries to view a demo itinerary summary and reference.

This is a front-end fictional demo. Flight times and fares are illustrative, no real flight inventory is queried, no booking is stored on a server, no ticket is issued and no payment is taken. The demo reference is not a real booking reference.
